# Studio Allegra — prévia comercial

Site responsivo, desenvolvido como uma **prévia independente**, não como site oficial do Studio Allegra.

## Publicação (GitHub Pages)

O projeto é estático e está pronto para **Branch: `main`, Folder: `/(root)`**, sem build, dependências ou configuração Node.

No repositório, abra **Settings → Pages → Build and deployment → Deploy from a branch** e selecione `main` e `/(root)`.

Endereço esperado: https://lzzamboniofc.github.io/StudioAllegra/

## Arquivos

- `index.html` — conteúdo, SEO básico, acessibilidade e links
- `styles.css` — identidade visual, animações e mobile-first
- `script.js` — menu responsivo, FAQ e ano atualizado no rodapé
